tuple:-
*******
-it is class template
-tuple is a STL utility used to stored fixed numbers of values of Different data types in single object

syntax declare tupple
tuple<datatype1,data type2,data type3> tupleName (value1,value2,value3)
tuple<int, string, double> t(101, "Asif", 85.5);
-we use get<index>(tupleName) to access elements in tuple
-tie is used to assign tuple element to existing variable
-pair stores only two Different or same data type values in pair but tuple different data type values

tie()
-tie() is function <tuple>used to bind existing valriable with elements present in tuple


#include <iostream>
#include <tuple>
#include <string>
using namespace std;

int main()
{
    tuple<int, string, double> t(101, "Asif", 25000.5);

    int id;
    string name;
    double salary;

    tie(id, name, salary) = t;

    cout << id << endl;
    cout << name << endl;
    cout << salary << endl;

    return 0;
}
